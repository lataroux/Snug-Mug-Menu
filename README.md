# Responsive Café Menu Web Page

A simple, responsive café menu web page built using HTML,CSS, and Javascript  This project focuses on front-end fundamentals such as semantic HTML structure, clean CSS styling, and responsive layout techniques commonly used in small business and restaurant websites.

## 📌 Features
- Semantic HTML5 structure using sections and articles
- Custom CSS styling with external stylesheet
- Responsive layout with flexible widths and mobile-friendly viewport
- Clear visual hierarchy for menu items and pricing
- Background imagery and typography styling for improved user experience
- Clean separation of structure (HTML) and presentation (CSS)

## 🛠 Technologies Used
- HTML5
- CSS3
- Javascript

## 📱 Responsiveness
The layout adapts to different screen sizes using relative widths and responsive design principles, ensuring usability on both desktop and mobile devices.
